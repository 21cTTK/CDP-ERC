# 嵌入式综设项目 - 机器人系统设计与实现（个人版）

这是一个 “树莓派ROS2就诊陪护机器人小车” 的代码仓库，目前项目已实现用于运动控制的STM32下位机的主要功能模块，包含了电机驱动、蓝牙通信、PID速度控制、PID角度控制等，后续会逐步完善 ROS2 节点和算法实现。

反正是学校某嵌入式综合设计课设的个人实现版，为后续小组实现的版本提前试错，提供关键模块的实现和其他经验参考。

## 开发环境

以下是本项目的开发环境说明，供复现使用：

- 目标芯片：STM32F103C8T6
- 调试平台：Keil μVision V5.39.0.0，使用 STLink 调试器进行下载和调试
- 底层依赖：标准外设库（SPL, STM32F10x_StdPeriph_Lib_V3.5.0），许可说明见 [LIB/LICENSE](./LIB/LICENSE)
- 硬件配置：按照 [物料清单](DOCS/BOM.pdf) 进行散件的选购与装配，按照 [引脚分配图](DOCS/Pinout.png) 进行硬件连接（后续会在立创硬件平台提供原理图及 PCB 设计图等具体配置）。

完成硬件搭建和软件配置后，克隆本仓库代码到本地，在 Keil 中打开 `prj.uvprojx` 工程文件，编译后下载到 STM32F103C8T6 芯片即可运行。注意本项目需要使用 AC5 进行编译（`Use default compiler version 5`）。

## 使用说明

上位机使用 HC蓝牙助手 或其他蓝牙调试工具，连接蓝牙模块（波特率 9600），发送指令控制小车运动。包头包尾均为 `#`。

### 主要功能

目前主要功能为操控小车运动，支持的指令如下（不含包头包尾）：

| 指令               | 功能                       | 补充说明                                   |
| ----------------- | -------------------------- | ----------------------------------------- |
| `MOTION+FORWARD`  | 前进                       | 默认车轮转速为 `240 RPM`                   |
| `MOTION+BACKWARD` | 后退                       | 默认车轮转速为 `240 RPM`                   |
| `MOTION+LEFT`     | 原地左转                   | 左轮 `-114 RPM`、右轮 `314 RPM`           |
| `MOTION+RIGHT`    | 原地右转                   | 左轮 `114 RPM`、右轮 `-314 RPM`           |
| `MOTION+STOP`     | 停止运动，并复位 PID 控制器 | 电机输入立即清零，PID 状态重置（增益保留）   |
| `MOTION+PAUSE`    | 经斜坡减速停止，保留 PID 状态 | 目标转速置 0，PID 参数与积分项不清零        |
| `FORWARD+<speed>` | 按指定速度前进             | `<speed>` 为浮点数，单位为 `RPM`           |

其他说明：

- 加上包头包尾的指令应该如 `#FORWARD+114.514#`，无需换行。
- 默认轮速可以在代码的 [cmtSys.c](./cmtSys.c) 中修改，后续可能会加入蓝牙修改默认轮速的功能。
- 每条指令都会回显执行结果，如 `CMD:"MOTION+FORWARD" - Y - Succeeded`；无法识别的指令回显 `CMD:"UNKNOWN." - N - Wtf is it even`。

### 调试功能

为了方便调整 PID 参数，代码提供了通过蓝牙发送指令来修改 PID 参数（以及偏航零偏）的功能，具体指令如下（不含包头包尾）：

| 指令                  | 功能                          | 补充说明                                              |
| -------------------- | ----------------------------- | ---------------------------------------------------- |
| `KP+<kp>`            | 修改轮速 PID 的比例系数 `Kp`   | 左右轮同时生效，默认 `0.5`                             |
| `KI+<ki>`            | 修改轮速 PID 的积分系数 `Ki`   | 左右轮同时生效，默认 `0.05`                            |
| `YAWKP+<kp>`         | 修改偏航 PID 的比例系数 `Kp`   | 默认 `3.1415926`                                     |
| `YAWKI+<ki>`         | 修改偏航 PID 的积分系数 `Ki`   | 默认 `0.52`                                          |
| `YAWOFFSET+<offset>` | 修改陀螺仪 Z 轴（偏航）零偏    | 默认 `0.94`，单位 `dps`，用于静止状态下的零点标定       |

其他说明：

- 指令同样需要包头包尾，如 `#KP+0.8#`，无需换行。
- 参数只接受**无符号十进制小数**（如 `0.8`、`12.5`），不支持负号、空格和科学计数法；解析到第一个非法字符即停止，输入非法时按 `0.0` 处理。
- 各个参数目前不做范围检查，由调试人员自行判断是否合理。
- `YAWKP` / `YAWKI` / `YAWOFFSET` 只是内存中的参数，一旦 `MPU6050_Init()` 再次执行（MPU6050 初始化失败后主循环会自动重试）就会被恢复为默认值。
- 所有修改都只保存在 RAM 中，复位或掉电后恢复为代码里的默认值（恢复定义在 [Enc.c](./HW/Enc.c) 与 [MPU6050.c](./HW/MPU6050.c) 的初始值宏定义）。
- 每条指令都会回显执行结果，如 `CMD:"SET+KP" - Y - KP=+0.8`；无法识别的指令回显 `CMD:"UNKNOWN." - N - Wtf is it even`。

调试期间系统还会按固定间隔主动上报运行数据（无需发送指令）：

| 输出                          | 内容                                                     | 补充说明                     |
| ---------------------------- | -------------------------------------------------------- | --------------------------- |
| `<actual>,<target>,<output>` | 左轮实测转速（RPM）、目标转速（RPM）、PID 输出（PWM 占空比） | 每 `520 ms` 上报一次         |
| `YAW:<dps>.`                 | 偏航角速度实测值（滤除噪声后），单位 `dps`                  | 同上，最近一次采样失败时不输出 |

上报的数值使用精简格式，与 `printf` 的 `%f` 输出不完全相同：

- `+` / `-` 号开头
- 去除末尾多余的零
- 超过 `1000` 用 `K`、超过 `1000000` 用 `M` 作单位

板载 LED 也参与了调试反馈：

- 收到任意完整数据包：`LED_MSG_RX` 闪烁 3 次（间隔 `114 ms`）。
- 指令被识别并执行：`LED_CMD_EXEC` 闪烁 3 次；指令无法识别：闪烁 6 次。
