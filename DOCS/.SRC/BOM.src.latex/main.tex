\subsection{供电方案}\label{sec:power}

\point{电机电源供电流程}

\begin{enumerate}[label=\arabic*., itemsep=3pt]
  \item \obsidianlink{\hyperref[pt:mb102]{MB102 电源板}}的圆头输入接 \obsidianlink{\hyperref[pt:battery]{12V 锂电池}}

        \imgrow{0.42}{PWR0.jpg}

  \item \obsidianlink{\hyperref[pt:mb102]{MB102 电源板}}插入面包板，通过 $3.3\,\mathrm{V}$ 引脚给单片机供电（具体连接方法自行搜索）

  \item 因为 MB102 没有直连输入的输出引脚，需要焊接一个\obsidianlink{\hyperref[pt:wiring]{XH2.54 接头}}来引出 $12\,\mathrm{V}$ 输出，再接到 \obsidianlink{\hyperref[pt:dcdc]{DC-DC 降压模块}}

        \imgrow{0.38}{PWR1.jpg}

  \item \obsidianlink{\hyperref[pt:dcdc]{DC-DC 降压模块}} 与面包板共地，正极输出接入两个\obsidianlink{\hyperref[pt:driver]{电机驱动}}的 \code{VM} 引脚（电机驱动的接线跳转查看）

        \imgrow{0.42}{PWR2.jpg}

  \item 以 \code{A} 组为例，\obsidianlink{\hyperref[pt:driver]{电机驱动}}输出口 \code{AO1}、\code{AO2} 分别接到\obsidianlink{\hyperref[pt:motor]{电机}}的红线/白线。没有规定的顺序，如果测试时运动方向与定义的“正向”不同，可以把两条线对换解决。

\end{enumerate}

\quad

\point{注意事项}

\begin{calloutwarning}
  \textbf{禁止把 MB102 电源板的输出引脚接到任何一个电机驱动的供电脚（\code{VM}）}
\end{calloutwarning}

\emph{烧点解析}：以下错误行为可能导致电源板、电源回路上的各种器件，甚至是单片机芯片被过大的电流烧坏

\begin{itemize}
  \item 多电源供电：同时用 STLink 和电源板给单片机供电
  \item 大负载电路不接独立电源：直接把引脚接到任何一个电机驱动的供电脚（\code{VM}）
  \item 错误测量方法：用万用表的电流档去测电压
\end{itemize}

\point{DC-DC 大功率降压模块}\label{pt:dcdc}

\emph{用途说明}：为什么电机电源不能全部接到 MB102 电源板的 $5\,\mathrm{V}$ 供电上？

\begin{itemize}
  \item MB102 电源板上的核心部件 AMS1117 线性稳压器工作电流为 $<700\mathrm{mA}$
  \item 减速电机在堵转情况下会产生很大的电流（现在选择的电机堵转电流为 $1.8\mathrm{A}$），
  \item 而这么狂野的电机我们有四个！全部堵转时电流达到 $1.8\mathrm{A}\times 4=7.2\mathrm{A}\approx 10\times 700\mathrm{mA}$
  \item 造化一般的 MB102 电源板在十倍的标称电流下不太可能不烧
\end{itemize}

综上所述，需要一个不经过电源板内部电路的模块直接为所有电机供电。其输入为唯一电源（锂电池 $12\,\mathrm{V}$），输出为电机驱动模块的电源输入（$5\,\mathrm{V}$ 的 \code{VM} 引脚），因此选择输入电压大于 $12\,\mathrm{V}$、输出 $5\,\mathrm{V}$、能承受 $7.2\,\mathrm{A}$ 最大电流的大功率 DC-DC 降压模块

\emph{采购建议}：

\begin{itemize}
  \item 购物软件搜索 \code{DC-DC大功率降压}，注意选取输入电压大于 $12\,\mathrm{V}$、输出 $5\,\mathrm{V}$、输出电流 $8\,\mathrm{A}$ 及以上的款式
  \item \weblink{https://e.tb.cn/h.jZIToYshCfepTDC?tk=CDyeTqn2dcL}{示例店铺}（商品名 \code{黑色3580 6-35V转【5V】8A}，参考价 $27.9$\,\yuan）
\end{itemize}

\emph{说明}：

\begin{itemize}
  \item 该模块输入电压范围为 $6\sim35\,\mathrm{V}$，本方案输入 $12\,\mathrm{V}$，输出 $5\,\mathrm{V}$、最大 $8\,\mathrm{A}$，满足电机驱动供电需求。
  \item 全部电机同时堵转的可能性较低，且若发生全部堵转，电机驱动模块可能先于 DC-DC 模块损坏（详见电机驱动模块说明）。
\end{itemize}

\emph{TB6612FNG 引脚实物图}：

\imgfigure{0.42}{IMG_20260914_111850_edit_5993387613461033.jpg}{TB6612FNG 引脚实物图}

TB6612FNG 电机驱动模块接入方向控制信号（\code{AINx}、\code{BINx}）、电机电源与接地（\code{VM}、\code{GND}）、用于控制转速的 PWM 信号（\code{PWMA}、\code{PWMB}）及使能（\code{STBY}）后，即可输出与 \code{VM} 电压一致的驱动信号 \code{AOx}、\code{BOx} 来驱动两组电机工作

\emph{采购建议}：

\begin{itemize}
  \item 购物软件搜索 \code{TB6612 电机驱动}，注意要买\textbf{两个}
  \item \weblink{https://e.tb.cn/h.8BFBFnvWQSAC6d3?tk=TN5GTqnQnG1}{示例店铺}（商品名 \code{TB6612FNG电机驱动模块（红板-焊好）}，参考价 $11.8$\,\yuan）
\end{itemize}

\emph{注意}：

本项目四轮小车只需控制左、右两组电机，组内运动状态保持一致。实测可只用一个驱动模块，左右组分别接到 \code{A} 和 \code{B} 两组引脚，并将组内输出并联，即可用一个控制信号和 PWM 信号控制一组两个电机。

虽然这样也能运行，但出于电流安全考虑，仍应使用两个驱动模块：TB6612FNG 峰值电流为 $3.2\,\mathrm{A}$，输出并联后电流相加，四个电机一起堵转时的 $7.2\,\mathrm{A}$ 远超一个模块的承受范围。

分成两个模块后，每侧两个电机一起堵转的 $3.6\,\mathrm{A}$ 仍不太安全。实际操作中虽不会经常吃满，但仍需做堵转保护，在软件层面限制每组的 PWM 占空比和持续时间。

\section{可选材料}\label{sec:optional}

\begin{itemize}
  \item \textbf{可选功能模块}
        \begin{itemize}
          \item OLED：增加一种显示调试信息或图形的方法

          \item 切割垫：保护桌面
          \item 剪钳：剪线头，可用于代替美工刀/刻刀削杜邦线
          \item 多格可拆零件盒：整理零件
        \end{itemize}
  \item \textbf{焊接相关非必需材料}
        \begin{itemize}
          \item 烙铁架：放置烙铁
          \item 高温海绵：清洁烙铁
          \item 焊接夹具：固定待焊器件
          \item 热缩套管：包裹焊好的裸露导线段
          \item 松香或助焊剂：增强焊锡流动性
          \item 吸锡带：清除多余焊锡
          \item 排针、排母：作为插头接口
        \end{itemize}
\end{itemize}
